# انگور ماله 🍇
دستیار صوتی فارسی برای اندروید.

## وضعیت نسخه اولیه
- اجرای فرمان با لمس دکمه میکروفون
- باز کردن گالری و دوربین
- انتخاب مخاطب و باز کردن شماره‌گیر برای تماس
- درخواست تشخیص گفتار فارسی با اولویت آفلاین (در صورت پشتیبانی سرویس گفتار گوشی)

## محدودیت‌های مهم
این نسخه هنوز کلمه بیدارباش دائمی «هی انگور ماله» را در پس‌زمینه اجرا نمی‌کند. اندروید ۱۲ برای میکروفون در پس‌زمینه محدودیت دارد و تشخیص گفتار آفلاین نیز به نصب بودن بسته زبان فارسی در سرویس گفتار دستگاه وابسته است. برای تماس، برنامه شماره‌گیر را باز می‌کند تا کاربر تماس را تأیید کند.

## ساخت APK
با GitHub Actions و اجرای workflow با نام **Build Android APK** ساخته می‌شود. فایل خروجی در بخش Artifacts همان اجرای workflow قرار می‌گیرد.
